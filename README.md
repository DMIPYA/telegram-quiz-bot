# Telegram Quiz Bot

**Тематические викторины на русском языке прямо в Telegram.**

Игрок выбирает категорию, отвечает на пять вопросов и получает пояснение к каждому ответу. Сложность определяет количество баллов, а доля правильных ответов — уровень игрока.

## Что внутри

- 164 вопроса в 12 категориях. В меню видны категории, в которых хватает вопросов для раунда.
- Четыре варианта ответа, пояснение и итог раунда. За верный ответ начисляется от 1 до 3 баллов.
- Статистика между перезапусками. Уровни: «Начинающий» (до 50%), «Любознательный» (от 50%), «Знаток» (от 75%) и «Эксперт» (от 90%).
- Генерация новых вопросов через NVIDIA NIM по команде `/generate` для администраторов.

## Запуск

Установите Python 3.11+, создайте виртуальное окружение и установите зависимости. Скопируйте [`.env.example`](.env.example) в `.env` и заполните параметры перед запуском.

```bash
python -m pip install -r requirements.txt
python bot.py
```

Затем откройте чат с ботом и отправьте `/start`.

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram от [@BotFather](https://t.me/BotFather). Нужен для запуска |
| `NVIDIA_API_KEY` | Ключ NVIDIA NIM. Текущая версия проверяет его при запуске |
| `ADMIN_USER_IDS` | Telegram ID администраторов через запятую. Даёт доступ к `/generate` |
| `NVIDIA_BASE_URL`, `NVIDIA_MODEL` | Дополнительные настройки провайдера и модели |

## Устройство проекта

| Файл | Роль |
| --- | --- |
| [`bot.py`](bot.py) | Команды, inline кнопки, ведение раунда и подсчёт очков |
| [`questions.json`](questions.json) | Вопросы, варианты ответа, правильный индекс, пояснение, категория и сложность |
| [`question_generator.py`](question_generator.py) | Генерация и проверка структуры новых вопросов |

Статистика хранится локально в `stats.json`. Для работы с несколькими экземплярами бота понадобится общее хранилище.
